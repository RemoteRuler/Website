## ✨ Features

- **Dynamic Hero Section**: Interactive 3D-like background animation with smooth transitions.
- **Custom Loading Experience**: Sequential "initializing" sequence with ambient background music.
- **Responsive Design**: Optimized for all screen sizes (Desktop, Tablet, Mobile).
- **Interactive Background**: Geometric grid with mouse-following mask effect and organic "Aurora" blobs.
- **Performance Optimized**: Built with Vanilla JS and CSS for maximum speed and zero dependencies.
