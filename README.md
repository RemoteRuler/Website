# Remote Ruler - Professional 4D Agency Website

![Remote Ruler Website](https://github.com/RemoteRuler/Website/blob/main/Logo/Remote_Ruler.png)

A high-end, immersive "Agency Style" portfolio website featuring **4D physics-based animations**, fluid dynamics, momentum scrolling, and an interactive audio experience.

## 🚀 Features

### 🌌 4D Immersive Experience
-   **Futuristic Warp Background**: A true 3D particle system simulating hyperspace travel (Canvas).
-   **Interactive Steering**: Moving the mouse changes the trajectory of the warp field.
-   **Momentum Scroll**: Physics-based scrolling inertia (`skewY` effect) for a tangible feel.

### 🎵 Interactive Audio System
-   **Smart Autoplay**: Handles browser autoplay policies by waiting for user interaction.
-   **Toggle Control**: Glassmorphism UI button with pulse animation.
-   **Visual Feedback**: Interface reacts to the audio state.

### 💎 "Glass & Light" Design
-   **Agency Dark Mode**: Deep `#0a0a0a` aesthetic with Neon Blue `#4facfe` accents.
-   **Holographic Cards**: Service cards feature a 3D glare effect on hover.
-   **Chromatic Text**: RGB-split aberration effects on interactive text.

## 🛠️ Technologies

-   **HTML5** (Semantic Structure)
-   **CSS3** (Variables, 3D Transforms, Flexbox/Grid, Glassmorphism)
-   **JavaScript (Vanilla)** (Canvas API, Physics Engine, IntersectionObserver, Audio Context)

## 📦 Setup & Installation

1.  **Clone the repository**
    ```bash
    git clone https://github.com/RemoteRuler/Website.git
    ```

2.  **Add Background Music**
    -   Place your audio file in the root directory.
    -   Rename it to `background-music.mp3`.

3.  **Run Locally**
    -   Simply open `index.html` in any modern browser.
    -   *Note: For the best Audio experience, running on a local server (Live Server) is recommended but not required.*
